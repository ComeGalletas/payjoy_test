# Memory index

Shared agent memory for this repository. One line per memory, pointing to a file in `memory/`:

```
- [Title](file.md) — one-line hook
```

Each memory file holds one fact, with frontmatter (`name`, `description`, `type`: user, feedback,
project or reference). Don't store what the repo already records (code, `docs/PLAN.md`, ADRs,
`docs/LOG.md`, git history); store what is non-obvious and would otherwise be lost between
sessions. Update a file rather than duplicating it; delete memories that turn out to be wrong.
